# InsightFlow design tokens

Dark "ocean" theme. The web Tailwind theme is derived from `tokens.css` — do not hand-pick colors.

| Token | Hex | Use |
|---|---|---|
| ocean-1 / ocean-2 | #072B40 / #0C4A66 | app background gradient |
| side / top | #06273A / #0A3346 | sidebar+rail / topbar |
| panel / panel-2 / inset | #0C3A54 / #0E4361 / #06222F | cards / lifted areas / code |
| border / hair | rgba(255,255,255,.12) / .07 | borders / hairlines |
| coral / coral-lab | #FB7A5C / #FF8E72 | accent buttons / labels+links |
| ink / sub / mut | #EAF3F7 / #A6C3D0 / #7BA0B2 | text primary/secondary/tertiary |
| success | #54D6A0 | positive status (sparing) |

Fonts: **Satoshi** (UI/display) + **JetBrains Mono** (code/data). `tabular-nums` on all figures.
Radii: 8px controls, 11–14px panels.
